## Evidence limitations

- The default Windows `bash.exe` could not create its WSL VM because the host
  reported `CreateVm/HCS/0x800705aa` (insufficient system resources). The same
  repository cross-check passed under installed Git Bash.
- The local Linux Zig link emitted Rust 1.97's `linker_messages` warning for the
  external wrapper's deprecated optimization spelling. Both binaries linked;
  source Clippy remained warning-denied and clean, and the official Linux build
  uses the native GitHub runner rather than this wrapper.
- Workspace `cargo package` is intentionally not a release gate: the
  `publish = false` Mise crate depends on the unpublished planner crate and
  cannot be prepared for crates.io as a workspace publication. The planner
  package itself verified cleanly; public distribution remains the versioned
  two-binary archive workflow.
